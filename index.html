GETTING STARTED

GlobalSub 이용 가이드

SRT 원본 파일만 있으면 시작할 수 있습니다. 번역 방법은 API 직접 연결과 수동 교환 중 선택하세요.

처음 이용한다면

먼저 SRT를 불러오고, 번역할 언어를 선택하세요.

‘미드나잇 시그널’은 학습용 샘플이며 새 프로젝트의 기본값이 아닙니다. 영상 파일은 선택 사항이며, 미리보기 중앙을 클릭하거나 영상을 끌어놓아 선택할 수 있습니다.

01

원본 SRT 불러오기

자막 스튜디오에서 SRT 불러오기를 눌러 한국어·영어 등 기존 자막을 선택합니다. 자동 추정한 원본 언어를 확인하세요.

02

번역할 언어 선택

언어 체크박스나 프리셋으로 대상 언어를 지정합니다. 언어를 선택한 것만으로 번역되지는 않습니다. 편집기 언어 탭의 완료·미번역 표시를 확인하세요.

03

방법 A · OpenAI API로 자동 번역

API · 설정에서 본인 API 키를 등록한 다음 스튜디오의 선택 언어 번역 시작을 누릅니다. 사용자 요금이 발생하며 브라우저 직접 연결이 차단되는 환경도 있습니다.

04

방법 B · API 없이 수동 번역

수동 번역 교환에서 대상 언어를 고르고 프롬프트를 복사합니다. ChatGPT에 붙여 넣은 뒤, 응답 JSON을 다시 넣어 검증 후 번역 적용을 누릅니다.

05

번역 검수 및 수정

자막 에디터에서 언어 탭을 선택하면 번역 진행 상태가 표시됩니다. 목록의 자막을 눌러 원문과 번역문을 비교하고 수정합니다. 시간 정보는 원본을 보존합니다.

06

SRT·ZIP 다운로드 및 백업

언어별 SRT 또는 완성된 언어를 묶은 ZIP을 다운로드합니다. 프로젝트 JSON을 백업하면 다음에도 이어서 작업할 수 있습니다. API 키·영상 파일은 백업되지 않습니다.

FAQ

자주 묻는 질문

언어 탭을 눌렀는데 번역 결과가 없어요.

언어 탭은 결과를 조회하는 기능입니다. 자동 번역은 API 등록 후 번역 실행 버튼을 눌러야 하고, API 없이도 수동 번역 교환에서 결과를 넣을 수 있습니다.

미드나잇 시그널이 무엇인가요?

동작을 체험하기 위한 가상 자막입니다. 실제 작업 파일이 아니며, 왼쪽의 ‘＋ 새 프로젝트’에서 비우거나 ‘예제 체험’에서 불러올 수 있습니다.

API 키를 연결해도 번역되지 않아요.

키를 등록했다고 연결 성공이 검증된 것은 아닙니다. OpenAI 계정 권한·요금·네트워크 오류 또는 브라우저 CORS 차단 가능성이 있습니다. 서비스는 중계 서버를 사용하지 않으며, 자동 요청이 막히면 수동 교환을 이용하세요.

내 SRT나 API 키가 서버에 저장되나요?

프로젝트는 브라우저에 저장되며 영상은 로컬에서만 미리 봅니다. API 키는 기본적으로 탭 메모리에만 있으며 선택적 암호화 저장도 가능합니다. 자동 번역할 때 자막 텍스트와 키는 브라우저에서 OpenAI로 직접 전달됩니다.

유튜브 자동 업로드도 되나요?

아닙니다. 다운로드한 언어별 SRT를 YouTube Studio에서 직접 업로드해 주세요.
